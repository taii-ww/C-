-Nền tảng để chạy chương trình: mỗi ngôn ngữ đều có 1 nền tảng riêng
nền tảng = môi trường + công cụ để chương trình chạy đc
+)Công cụ (compiler): biến code của bạn thành thứ có thể chạy -> biến code thành mã trung gian
+)Môi trường (runtime): có thể hiểu và chạy đc code -> biến code thành mã nhị phân (0,1) để cpu có thể hiểu và chạy
.NET là nền tảng để chạy C#
.NET bao gồm: .NET Runtime -> môi trường 
              compiler (csc) -> công cụ
Compiler có thể khác nhau ở mỗi ngôn ngữ
vd: c# có compiler là csc nằm trong .NET SDK
    java có compiler là javac nằm trong JDK
=> Các bước để chạy chương trình (có mã trung gian) là:
Viết code -> compiler -> runtime -> cpu chạy

**Lưu ý: 
-Chỉ ngôn ngữ có mã trung gian (java, c#, python,...) thì compiler mới biến code thành mã trung gian
-Các ngôn ngữ ko có mã trung gian (C, C++,...) thì compiler biến trực tiếp code thành mã nhị phân (0,1), runtime chỉ hỗ trợ thư viện

=> Các bước để chạy chương trình (ko có mã trung gian) là:
Viết code -> compiler -> cpu chạy

.split(): dùng để tách chuỗi thành nhiều phần tử nhỏ dựa vào ký tự hoặc chuỗi phân cách
vd: string s = "apple,banana,orange";
string[] arr = s.Split(',');
Kết quả: arr sẽ chứa: "apple", "banana", "orange"

s.Split(','); → tách chuỗi khi gặp dấu phẩy ,
s.Split(' '); → tách chuỗi khi gặp dấu cách (space)

StringSplitOptions.RemoveEmptyEntries => dùng để loại bỏ phần tử rỗng khi đã tách chuỗi
vd: -Ban đầu input = "  nGuYeN    vaN   tAi  "
input.Split(' ', StringSplitOptions.RemoveEmptyEntries);
-Nếu chỉ Split(' ') thì sẽ ra:
input = ["", "", "nGuYeN", "", "", "", "vaN", "", "", "tAi", "", ""]
-Nhưng có RemoveEmptyEntries thì sẽ thành:
["nGuYeN", "vaN", "tAi"]

Lưu ý: Khi dùng split thì đa số kiểu dữ liệu sẽ là kiểu mảng chuỗi String[]
vd: string[] words = input.Split(' ');

COLLECTIONS (TẬP HỢP DỮ LIỆU)
Collection được sinh ra để khắc phục sự hạn chế của mảng (array)
Mảng phải khai báo kích thước trước
Collections có thể tự động tăng kích thước
Quản lý dữ liệu linh hoạt và hiệu quả hơn

Các loại collections:
+)ArrayList
+)Stack
+)Queue
+)SortedList
+)Hashtable

Stack -> Lưu dữ liệu theo LIFO (vào sau ra trước)
Khai báo: Stack<int> s = new Stack<int>();

Queue -> Lưu dữ liệu theo FIFO (vào trước ra trước)
Khai báo: Queue<string> q = new Queue<string>();


arraylist -> dùng để lưu danh sách nhiều kiểu dữ liệu khác nhau.
Khai báo: ArrayList ar = new ArrayList();
var: ko phải kiểu dữ liệu mà là ừ khóa để C# tự suy luận kiểu dữ liệu từ giá trị gán.
vd: var x = 10
C# hiểu thành: int x = 10; Tương tự với String, double,....
-> var đc dùng nhiều khi sử dụng arraylist 

Hashtable -> dùng để lưu dữ liệu theo cặp key - value.
          -> Thứ tự ko cố định
Khai báo: Hashtable ht = new Hashtable();
Cố định: ht(KEY, VALUE)
DictionaryEntry: Là kiểu dữ liệu dùng khi duyệt Hashtable hoặc SortedList.
vì nó chứa key và value

SortedList -> dùng để lưu dữ liệu theo cặp key - value.
           -> Thứ tự cố định
Khai báo: SortedList list = new SortedList();

List<T> -> Lưu danh sách dữ liệu cùng một kiểu
List<T> khác biệt với các collections mà cũng lưu danh sách dữ liệu cùng một kiểu như stack hay queue chính là List<T>:
+) Rất linh hoạt
+)Có thể truy cập theo index (list[0], list[1])
+)Thêm/xóa ở nhiều vị trí
Khai báo: List<int> l = new List<int>();

Phương thức thêm phần tử:
Stack : .Push(..)
Queue : .Enqueue(..)
ArrayList, Hashtable, SortedList, List<T> : .Add(..)


Từ các collections, ta có thể phân ra thành 2 kiểu: generic và non-generic
+)Non-generic: ArrayList, Stack, Queue, Hashtable, SortedList
+)Generic: List<T>, Stack<T>, Queue<T>, Dictionary<TKey,TValue>

| Non-generic                | Generic                      |
| -------------------------- | ---------------------------- |
| Chứa **mọi kiểu dữ liệu**  | Chỉ chứa **1 kiểu xác định** |
| Dùng **object**            | Dùng **<T>**                 |
| Phải **ép kiểu (casting)** | **Không cần ép kiểu**        |
| Dễ lỗi và chậm hơn         | **An toàn và nhanh hơn**     |
